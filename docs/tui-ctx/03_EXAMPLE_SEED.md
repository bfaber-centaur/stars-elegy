What this seed is testing:

- battlefield + inspector + event detail fit in one stable frame;
- the replay cursor is a first-class object;
- the event log is causal and numerical rather than cinematic prose;
- selection links the right-hand details to a visible battlefield actor;
- important destruction can be marked on the timeline.

What is deliberately unresolved:

- whether the battlefield needs a true coordinate grid;
- whether stack glyphs should be abstract IDs, tiny ship silhouettes, or names;
- whether shields/armor belong here;
- exact combat sequencing and terminology;
- whether a vertical timeline works better;
- whether a small event ledger beats the prose-style event panel.

Please create studies that challenge this layout rather than merely polishing it.
